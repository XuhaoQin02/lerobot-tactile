# LeRobot Tactile Project Page

Project website for **Which Physical Tactile Cues Matter for Contact-Rich Imitation Learning? A Controlled Real-Robot Study**.

The site is plain HTML/CSS and is published from the `main` branch with GitHub Pages.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
